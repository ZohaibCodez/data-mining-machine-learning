# Contributing

This is a personal coursework repository tracking my Data Mining & Machine Learning assignments at PUCIT, so it isn't actively seeking feature contributions. That said, corrections and suggestions are welcome:

## Reporting an Issue

Found a bug, typo, or error in a notebook? Please [open an issue](https://github.com/ZohaibCodez/data-mining-machine-learning/issues) with:

- The notebook/file affected
- A clear description of the problem
- A suggested fix, if you have one

## Suggesting a Fix via Pull Request

1. Fork the repository
2. Create a branch (`git checkout -b fix/notebook-typo`)
3. Make your change
4. Commit with a clear message
5. Open a pull request describing the fix

## Ground Rules

- Keep changes focused and minimal — this repo mirrors coursework as it's completed, so avoid restructuring existing assignments.
- Follow the existing naming convention (`Assignment_XX/`, `Lecture N <Topic>.ipynb`).
- Be respectful — see the [Code of Conduct](CODE_OF_CONDUCT.md).

Thanks for taking the time to help improve this repo!
