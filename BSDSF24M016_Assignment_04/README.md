# 📓 Assignment 04 — Linear Regression (Coursera ML Specialization Lab)

The graded linear regression lab from the Coursera Machine Learning Specialization (Course 1, Week 2), as part of the [Data Mining & Machine Learning](../README.md) coursework.

## 📂 Contents

### `Assignment Linear Regression/`
Linear regression with one variable to predict restaurant franchise profit from city population.
- [`Linear_Regression.ipynb`](Assignment%20Linear%20Regression/Linear_Regression.ipynb) — cost function, gradient descent, and prediction implemented from scratch, checked against `public_tests.py`
- `data/ex1data1.txt`, `data/ex1data2.txt` — single- and multi-feature training data
- `utils.py`, `public_tests.py` — provided helper and autograder functions

> The supporting "Lecture 6 labs" (feature engineering, feature scaling, scikit-learn, multiple-variable regression) are kept locally for reference but are not tracked in this repo.

## ▶️ Running

From the repo root:

```bash
jupyter notebook "BSDSF24M016_Assignment_04/Assignment Linear Regression/Linear_Regression.ipynb"
```
